# AI 任务管线（AI Task Pipeline）

基于 VS Code 的 AI 驱动任务调度扩展，支持模块冲突避免与看板式管线管理。

## 功能特性

- **五池看板管线**：待处理 → 处理中 → 待审核 → 已完成 / 已终止
- **模块冲突自动检测**：防止两个任务同时修改同一代码模块
- **AI 代理集成**：通过 `vscode.lm` API 实现自主任务处理与工具调用
- **操作日志记录**：完整记录所有文件读取、写入、编辑和命令执行操作
- **差异查看器**：使用 VS Code 原生差异编辑器对比文件修改前后内容
- **高危操作审批**：对危险操作（如命令执行）提供审批工作流，暂停等待用户确认
- **回滚支持**：一键撤销 AI 的所有文件修改，任务标记为已终止

## 使用方法

1. 从活动栏或命令面板打开任务面板
2. 添加任务（填写标题和描述）
3. 调度器自动选取无冲突任务并由 AI 处理
4. 在"待审核"列查看 AI 修改 —— 点击"查看详情"查看操作记录
5. 点击"查看差异（Diff 视图）"打开原生差异编辑器
6. 批准、拒绝（可选择重新处理或回滚）或终止任务

## 技术栈

- TypeScript + VS Code Extension API
- Webview UI（看板面板 + 侧边栏概览）
- `vscode.lm` API（语言模型集成）
- 自定义虚拟文档提供者（差异视图）

## 开发与构建

```bash
# 安装依赖
npm install

# 编译
npm run compile

# 打包为 VSIX
npm run package
```
